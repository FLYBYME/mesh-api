## Why these four

They are what a real app hit within a day of the framework existing. Each one is small; the reason
they matter is that every app built after this one either inherits the workaround or re-invents it.

### 2. `SurfaceDefinition` does not support `views`

`07-routing.md` describes `views` as how an app routes inside its own subtree. The type has no such
field, so `apps/domains.ts` wires its own view switching. Build it, and make `apps/domains.ts` use
it — if the app does not get simpler, the design is wrong and you should say so rather than ship it.

Views must compose with the scoped router that now exists on `ctx.router`: a view's route is
relative to the app's mount prefix, and the app must not need to know its own prefix to declare one.

### 3. `AppStateContainer` has no store helpers

`11-example-kanban.md` uses `ctx.state.set({ ... })` and `ctx.state.get()`. The implementation
exposes only the reactive primitives (`signal`, `computed`, `resource`, `persisted`, `effect`).

**Decide which is right and reconcile them, rather than adding the doc's shape reflexively.** An
untyped dictionary store sitting beside fine-grained signals is arguably a worse API — it invites
coarse whole-object writes that defeat the fine-grained updates this framework exists for. If you
conclude the primitives are correct, fix spec 11 instead and say so. If you add the helpers, they
must be typed, and they must not become a second source of truth for state a signal already holds.
Either answer is acceptable; an unargued one is not.

### 5. `Badge` has no reactive variant binding

Its variant cannot follow a signal, so status that changes cannot change colour. Match how every
other component in `src/runtime/dom/` accepts reactive props — do not invent a second convention.

### 6. `Table` cell typing is weaker than it needs to be

Tighten it. The constraint below is absolute: no `as any`, no `as unknown as`, no `as never`. If a
type genuinely cannot be expressed, leave it and say so in your summary — an honest gap beats a cast
that silently makes a wrong call type-check.
